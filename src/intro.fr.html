Éditeur GTFS

edit.gtfs.zone est un éditeur de données de transport GTFS dans le navigateur. Toutes les données restent dans votre navigateur : aucun serveur, aucun compte.

  • Charger un flux : depuis une URL ou un fichier zip GTFS local.
  • Modifier n'importe quelle table : agences, lignes, arrêts, voyages, horaires de passage, calendriers, tarifs et tous les autres fichiers.
  • Placer les arrêts sur la carte : ajoutez et positionnez les arrêts directement sur la carte.
  • Vérifier le flux : validation au fil de l'eau par rapport à la spécification GTFS Schedule.
  • Exporter un zip : téléchargez un flux GTFS prêt à publier.

Fait partie de gtfs.zone, des outils libres pour GTFS et GTFS Realtime. Voir la référence GTFS Schedule.

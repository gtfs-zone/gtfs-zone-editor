GTFS-Editor

edit.gtfs.zone ist ein browserbasierter Editor für GTFS-Fahrplandaten. Alle Daten bleiben in Ihrem Browser: kein Server, kein Konto nötig.

  • Feed laden: von einer URL oder aus einer lokalen GTFS-ZIP-Datei.
  • Jede Tabelle bearbeiten: Verkehrsunternehmen, Linien, Haltestellen, Fahrten, Haltezeiten, Kalender, Tarife und jede andere Datei.
  • Haltestellen auf der Karte setzen: Haltestellen direkt auf der Karte hinzufügen und platzieren.
  • Feed prüfen: laufende Validierung gegen die GTFS-Schedule-Spezifikation.
  • ZIP exportieren: Laden Sie einen veröffentlichungsfertigen GTFS-Feed herunter.

Teil von gtfs.zone, Open-Source-Werkzeugen für GTFS und GTFS Realtime. Siehe die GTFS-Schedule-Referenz.
